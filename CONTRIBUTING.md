# Contributing

Thanks for helping keep Nepal reference data accurate.

- Include a primary source URL, retrieval date, and source coverage for data changes.
- Preserve official spellings and codes. Keep identifiers as strings so leading zeroes are not lost.
- Do not fill gaps with estimates or unsourced directories.
- For postal changes, include the changed source rows or an official notice in the pull request description.
- If a source does not state its license or reuse terms, do not assign one to the source data.

Run `npm test` before opening a pull request. Explain dataset count changes with an official source change.
